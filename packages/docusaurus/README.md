Generate Docusaurus pages and sidebar entries from an OpenCLI document.

```sh
npm install @clidoc/docusaurus @docusaurus/core @docusaurus/preset-classic react react-dom
```

Export a document from your CLI, for example `mycli docgen --output cli.json`, then add the plugin in `docusaurus.config.js`:

```js
const clidocPlugin = require('@clidoc/docusaurus');

module.exports = {
  title: 'My CLI',
  url: 'https://example.com',
  baseUrl: '/',
  markdown: { format: 'md' },
  presets: [['classic', { docs: { routeBasePath: '/', sidebarPath: './sidebars.js' }, blog: false }]],
  plugins: [
    [
      clidocPlugin,
      {
        input: 'cli.json',
        outputDir: 'docs/cli',
        basePath: '/cli',
      },
    ],
  ],
};
```

In `sidebars.js`:

```js
module.exports = { docs: [{ type: 'autogenerated', dirName: '.' }] };
```

Run `npx docusaurus start`. The generated pages appear in the autogenerated sidebar next to your handwritten pages. Add the generated files to `.gitignore`:

```gitignore
docs/cli/mycli*.md
docs/cli/.clidoc-generated.json
```

## Notes

- `input` is a JSON/YAML path relative to the site directory or a parsed document. Docusaurus loads its config without top-level `await`, so pass a path.
- Regeneration only removes files listed in `.clidoc-generated.json` and never overwrites a file it does not own, so handwritten pages can share `outputDir`.
- Filenames are readable, such as `mycli.md` and `mycli-validate.md`. Routes come from `basePath` and stay stable when unrelated commands are added.
- Build scripts can call `writeDocusaurus(document, { outputDir, basePath })` directly.
